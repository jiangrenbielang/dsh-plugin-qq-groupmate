## 一、打不开 / 白屏 / 样式乱

### 1.1 双击 index.html 白屏，或样式全乱
- **现象**：页面空白，或能打开但布局全乱、按钮没样式。
- **原因**：RP-Hub 依赖 5 个 CDN 脚本（Vue、Tailwind、marked、DOMPurify、SortableJS），在 `<head>` 里同步加载且无本地兜底。断网、被墙、CDN 抽风时：Vue 挂了 → 整个应用白屏（控制台报 `Vue is not defined`）；Tailwind 挂了 → 样式全丢；marked/DOMPurify 挂了 → 聊天内容渲染不出来。
- **解决**：联网打开；或把 5 个 CDN 文件下载到本地（如 `assets/vendor/`）并改 index.html 引用。字体（Google Fonts）挂了影响最小，只是换回退字体。

### 1.2 打开后弹"网站公告"，10 秒内关不掉
- **现象**：首次打开弹公告弹窗，关闭按钮点了没反应，以为卡死。
- **原因**：公告弹窗设计上要等 10 秒倒计时结束才能关（防误关），不是 bug。
- **解决**：等 10 秒再关；关过一次后写进 localStorage，不再弹。

### 1.3 换浏览器 / 换目录 / 用 Live Server 换端口后，角色和聊天"不见了"
- **现象**：数据全没了，像新装的。
- **原因**：所有数据存在浏览器的 IndexedDB（库名 `RPHubDB`）里，按"站点来源"隔离。`file://` 双击打开时不同浏览器隔离策略不一致；用 Live Server 换端口、换目录就是新来源，等于空库。**数据没有云端备份，清浏览器站点数据 = 全部丢失。**
- **解决**：固定用同一种方式打开（推荐固定目录 + 固定端口）；换浏览器/清缓存前，先导出角色卡（JSON/PNG）和"全部分支聊天"（JSONL）。

## 二、API 配置与对话报错

### 2.1 发消息后红字 `API Error: 401`
- **原因**：API Key 没填、填错，或 Key 填到了别的 provider 槽里（Key 按 provider 分开存，切换 provider 后 Key 跟着切，用户常在别的服务商槽里填了 DeepSeek 的 Key）。
- **解决**：设置里选对当前 provider，把 Key 填到当前选中的那个槽；填完再发。

### 2.2 红字 `API Error: 404`
- **原因**：API 地址填错。RP-Hub 会自动补 `/v1`：填 `https://api.deepseek.com` 会自动变 `/v1`（正确）；但填了带 `/v2` 或完整端点（如 `/v1/chat/completions`）的地址，会拼成 `/v2/v1` 或 `/v1/chat/completions/v1`，必然 404。
- **解决**：API 地址只填根地址（域名，或最多到 `/v1`），不要填完整端点。

### 2.3 报 `Failed to fetch` / TypeError（网络错误）
- **原因**：纯前端直连第三方 API，对方不开 CORS 就报这个。RP-Hub 没有内置代理。
- **解决**：换一个支持 CORS 的 API 服务；或自建反向代理转发。

### 2.4 一直转圈，2 分钟后才报"API 响应超时"
- **原因**：超时是"无响应超时"（默认 120 秒），只要流式输出持续有数据就不算超时；主对话**没有自动重试**。
- **解决**：等 2 分钟没反应就点消息上的"重新生成"手动重试；持续超时查网络/代理/服务端负载。

### 2.5 模型名填错
- **现象**：报 `Model Not Exist` 之类（错误原文来自服务端）。
- **原因**：不点"获取模型列表"时模型名必须手填，填错由服务端返回 400。
- **解决**：设置里点"获取模型列表"从下拉选，或核对服务端文档里的模型名。

### 2.6 费用显示 `--`
- **原因**：费用统计走的是特定中转站（new-api 类）的 `/api/log/token` 接口，普通 OpenAI 兼容端点没有这个接口，请求失败只静默跳过。
- **解决**：不是 bug，普通 API 端点不显示费用属正常。

### 2.7 停止生成后已收到的内容还在，但 token 照扣
- **原因**：中止只停输出，已流式收到的 token 仍计入用量。
- **解决**：正常现象，别反复点停止。

## 三、生图

### 3.1 生图失败 / 卡片一直"排队中"然后变红字
- **原因**：生图走的是单独配置的 NAI 生图服务，需要单独的 `imageGenKey`（生图 token），**和对话 API Key 是两回事**。只配了对话 Key 生不了图。
- **解决**：设置里填生图 Key；卡片显示 `job.error` 原文时按原文排查（额度不足、模型不支持等）。

### 3.2 画师风格"不生效" / 换角色后风格变了
- **原因**：画师串是**全局设置**（内置 6 种风格 + 自定义），不随角色卡走；自定义画师填了但没选 `custom` 风格也白填。
- **解决**：在设置里选风格；自定义画师要选"custom"。

### 3.3 提示词太短，无法重新生成
- **原因**：单张重新生成（reroll）要求标签 ≥2 个。
- **解决**：让模型输出更多标签，或手动补标签。

### 3.4 自动生图开关开了但不出图
- **原因**：自动生图依赖两个内置条目——"NAI画图正则"（正则脚本）和"自动生图"（世界书条目），默认关闭，且**不能删**。删了之后开关会提示"未找到'自动生图'世界书条目"。
- **解决**：检查这两个条目还在且启用；设置里 imageGenKey 变化时会强制重建这两个条目（手动改过会被覆盖，属正常）。

### 3.5 生图 token 泄露风险
- **原因**：生图 URL 里明文带 token，随聊天记录保存；导出聊天/截图可能泄露。
- **解决**：别把带生图卡片的聊天记录截图/导出发给别人。

## 四、角色卡导入导出

### 4.1 导入 PNG 报"PNG解析失败: No character data found in PNG"
- **原因**：PNG 卡里没有 `chara`/`ccv3` 文本块，也没有可识别的内嵌 JSON/base64；某些站导出的"PNG 卡"其实是普通图片；或用了 zTXt 压缩（RP-Hub 只支持未压缩的 iTXt）。
- **解决**：换 JSON 格式的卡；或确认文件真的是角色卡 PNG。

### 4.2 导入 JSON 报"JSON解析失败"
- **原因**：文件不是合法 JSON，或结构为空。
- **解决**：用文本编辑器打开确认是 JSON；从正规来源重新下载。

### 4.3 导入不报错，但角色内容"缺东西"（世界书/正则/开场白没了）
- **原因**：① 卡的字段名不规范（有别名兼容，但太偏门的字段认不出）；② **scope 为 `global` 的世界书条目导入时会被过滤**，落到全局配置里，角色卡编辑列表看不到。
- **解决**：检查全局配置里有没有；字段问题只能换卡或手动补。

### 4.4 导入超过 100MB 的文件
- **现象**：报"角色卡文件无效或超过 100 MB"。
- **解决**：压缩/换小文件。

### 4.5 导出 PNG 失败
- **原因**：头像引用第三方图片且对方不带 CORS 头时，导出 PNG 会失败。
- **解决**：先上传本地头像再导出 PNG；或导出 JSON。

### 4.6 导入失败会不会破坏现有数据
- **不会**：角色卡导入失败会回滚；聊天记录导入失败时"原记录未被覆盖"。可以放心试。

## 五、世界书（lorebook）

### 5.1 世界书条目"不触发"
- **排查顺序**：
  1. 关键词是否出现在**最近 2 条消息**里（默认 scanDepth=2，只扫最近几条的拼接文本）；
  2. 条目是否启用（enabled）；
  3. 正则写法对不对——**写坏的正则静默跳过，界面无任何提示**（只写控制台 warn），这是最高频的"不触发"原因；
  4. 条目是不是 `global` 作用域（global 条目在全局配置里管理，角色卡列表看不到）；
  5. 概率设置（默认 100%，但每轮重新抽签，调低了会"时灵时不灵"）。
- **解决**：按上面顺序查；正则用 `/.../` 包裹时注意转义。

### 5.2 条目内容跑到奇怪的位置
- **原因**：position/depth/order 配置问题。`at_depth` 条目会以 `[条目名]\n内容` 形式插入为一条 user 消息，在上下文查看器里占一层。
- **解决**：检查条目的 position（7 种注入位置）和 depth。

### 5.3 正则脚本"没生效"
- **原因**：正则脚本有 minDepth/maxDepth 深度限制，深度按数组位置算（depth = 长度-1-下标），设置不对就过滤掉了。
- **解决**：检查正则脚本的深度设置。

## 六、记忆功能

### 6.1 总结记忆报"请先选择总结模式副模型"
- **原因**：总结记忆必须单独配一个副模型（classicModel），没选就用不了。
- **解决**：设置里选总结副模型。

### 6.2 向量记忆报"请先选择向量嵌入模型"
- **原因**：向量记忆需要单独的 embeddingModel，走 `/v1/embeddings` 接口；有的中转站 embeddings 收费或不支持。
- **解决**：选嵌入模型；不支持就换总结记忆模式。

### 6.3 换嵌入模型后记忆"变傻了"
- **原因**：不同嵌入模型的向量空间不同，换模型后旧向量相似度失真。
- **解决**：换嵌入模型后建议清空向量记忆重新积累。

### 6.4 清空聊天把记忆也清了
- **原因**：`clearChat` 会连同记忆一起清空，且不可撤销（弹窗有提示）。
- **解决**：清空前确认；要留记忆就只删消息别清空。

### 6.5 记忆开启后上下文"跳变"
- **原因**：旧对话被压缩移除只发生在对应轮次已生成记忆时；空轮次（emptyTurns）也会被移除，导致上下文跳变。
- **解决**：属机制特性；介意就调大保留层数或关记忆。

## 七、剧情分支

### 7.1 切换分支提示"正在停止生成，请稍后再切换分支"
- **原因**：切换分支前必须停止生成（最多等 3 秒），停不下来就取消切换。
- **解决**：等生成结束再切。

### 7.2 切换分支/角色时刷新页面丢消息
- **原因**：切换前会先保存，但切换过程中刷新可能丢当前分支未保存的尾部消息。
- **解决**：等切换完成（提示出现）再刷新。

### 7.3 分支聊天导入报"不支持的分支聊天版本"
- **原因**：分支聊天 JSONL 有版本号，版本 1 的文件只能导给自己/同版本。
- **解决**：用同版本 RP-Hub 导出导入。

## 八、UI 模板 / 变量

### 8.1 反复提示"变量分析失败，下次请求将自动修正"，自己的消息前面多了一段字
- **原因**：模型输出的 `<ui_template_updates>` 变量块和模板 schema 对不上（变量名、类型、id 不匹配），自动修正机制会把修正指令拼到你的消息开头，让模型重出变量块。**不是消息被篡改，是正常机制。**
- **解决**：检查模板变量名与 schema 一致；别手动删修正前缀，让它自动修正一轮；仍失败就关掉"主模型分析"改用副模型分析，或直接关变量分析。

### 8.2 模型输出 HTML 面板显示异常（白边/截断/外链加载失败）
- **原因**：模型输出的 HTML 在 sandbox iframe 里执行，外链资源可能加载失败；iframe 高度在 onload 后 100ms 才调整，动态内容可能截断。
- **解决**：属机制限制；让模型少用外链资源。

## 九、发图 / 识图

### 9.1 发图提示"请先在设置中配置识图模型"
- **原因**：发图前必须配置 visionModel（识图模型），默认空。
- **解决**：设置里配识图模型（用主 API 地址 + 支持多模态的模型）。

### 9.2 提示"请先移除识别失败的图片"
- **原因**：图片识别失败后发送会被拦截。
- **解决**：移除失败图片再发；单次最多 3 张、每张 ≤20MB。

## 十、其他

### 10.1 存储空间不足
- **现象**：提示"存储空间不足，聊天记录未能保存"或"存储空间不足，无法保存"。
- **原因**：IndexedDB 配额满了（角色卡头像全量 base64 存库里，卡多了很容易撑爆）。
- **解决**：删除旧角色、导出备份后清理；浏览器设置里清该站点数据（注意会全清）。

### 10.2 发消息后立刻关标签页，最后 1-2 条消息丢了
- **原因**：聊天保存是防抖定时（生成中 1500ms、平时 300ms），没有关页兜底。
- **解决**：发完等 1-2 秒再关；切角色/切分支/删角色前会自动保存，等切换完成即可。

### 10.3 模型"只出思考不出正文" / 正文被吞
- **原因**：`<thinking>`/`<think>`/`<cot>` 标签会被解析剥离，模型输出不成对/未闭合标签时正文会被吞。
- **解决**：换模型或换提示词；属模型输出格式问题。

### 10.4 提示"API 未返回抗截断输出" / 工具调用报错
- **原因**：防截断模式只对 Gemini 类模型生效，且要求 API 支持工具调用；不支持的站点会报错（空工具回会自动重试最多 3 次）。
- **解决**：关掉防截断，或换支持工具调用的 API。

### 10.5 更新检查失败
- **原因**：每 20 秒向远端查版本，失败静默忽略，不影响使用。
- **解决**：不用管。
